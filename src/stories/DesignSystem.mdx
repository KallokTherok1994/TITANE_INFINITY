# TITANE∞ Design System

## Color Palette

### Primary Colors
- **Background**: `#0A0A0A` (dark), `#FFFFFF` (light)
- **Text**: `#E0E0E0` (dark), `#1A1A1A` (light)
- **Accent**: `#00D4FF` (cyan), `#FF00D4` (magenta)

### Semantic Colors
- **Success**: `#00FF85`
- **Warning**: `#FFB800`
- **Error**: `#FF4444`
- **Info**: `#00D4FF`

## Typography

### Font Families
- **Heading**: Inter, sans-serif
- **Body**: Inter, sans-serif
- **Mono**: JetBrains Mono, monospace

### Font Sizes
- **xs**: 0.75rem (12px)
- **sm**: 0.875rem (14px)
- **base**: 1rem (16px)
- **lg**: 1.125rem (18px)
- **xl**: 1.25rem (20px)
- **2xl**: 1.5rem (24px)
- **3xl**: 1.875rem (30px)
- **4xl**: 2.25rem (36px)

## Spacing

Based on 4px base unit:
- **1**: 0.25rem (4px)
- **2**: 0.5rem (8px)
- **3**: 0.75rem (12px)
- **4**: 1rem (16px)
- **6**: 1.5rem (24px)
- **8**: 2rem (32px)
- **12**: 3rem (48px)
- **16**: 4rem (64px)

## Border Radius
- **sm**: 0.25rem (4px)
- **md**: 0.5rem (8px)
- **lg**: 0.75rem (12px)
- **xl**: 1rem (16px)
- **full**: 9999px

## Shadows
- **sm**: `0 1px 2px rgba(0, 0, 0, 0.05)`
- **md**: `0 4px 6px rgba(0, 0, 0, 0.1)`
- **lg**: `0 10px 15px rgba(0, 0, 0, 0.1)`
- **xl**: `0 20px 25px rgba(0, 0, 0, 0.15)`

## Components

### Button Variants
- **Primary**: Cyan accent, white text
- **Secondary**: Gray background, light text
- **Outline**: Transparent with border
- **Ghost**: No background, hover effect

### Card
- Dark background with subtle border
- 8px border radius
- Hover: subtle glow effect

### Input
- Dark background, light border
- Focus: cyan border glow
- Error: red border

## Accessibility

All components follow WCAG 2.1 AA standards:
- Minimum contrast ratio: 4.5:1
- Keyboard navigation support
- ARIA labels for screen readers
- Focus indicators
