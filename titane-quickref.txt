📅 Démarrage journalier:
   ./titane health && git pull

🔄 Après git pull (si package.json modifié):
   ./titane repair

🐛 Correction erreurs:
   ./titane fix

🧪 Avant commit:
   ./titane fix && npm run check && npm test

📦 Release production:
   git checkout MAIN && ./titane full

🆘 Reset complet (en cas de problème):
   ./titane clean && ./titane repair && ./titane fix
