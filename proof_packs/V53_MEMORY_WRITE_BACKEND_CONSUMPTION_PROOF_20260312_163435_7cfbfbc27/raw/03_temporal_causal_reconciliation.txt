## FIX VECTOR (V53 PHASE 4)

To achieve Memory Write Before Send = TRUE:

Option A: await before send
- Change void to: await memoryIntegration.saveInteraction() [BLOCKING]
- Risk: Adds latency to every send (200-500ms)
- Benefit: Guarantees write at T0.5, reads at T1, has token in envelope

Option B: Pre-write interactively
- Save user message BEFORE building envelope
- Timing: T0.5 (new user msg saves previous interaction)
- Benefit: Low latency, memory always available

- Don't pre-load memory, DEFER read until after backend returns
- Timing: Read at T7, re-build envelope async
- Problem: Can't use memory in THIS request, only next request
