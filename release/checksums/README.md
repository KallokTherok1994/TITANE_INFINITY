# release/checksums/

This directory contains SHA256 checksum files for TITANE∞ release artifacts.

## Naming convention

```
RELEASE_ARTIFACTS_CHECKSUMS_<version>.txt
```

Each file is generated by `scripts/generate-release-checksums.sh` after a Tauri production build. The file lists SHA256 hashes for:

- `titane-infinity` (binary)
- `TITANE-Infinity_<version>_amd64.AppImage`
- `TITANE-Infinity_<version>_amd64.deb`
- `TITANE-Infinity-<version>-1.x86_64.rpm` (if present)

## Usage

```bash
# Generate checksums after a build
bash scripts/generate-release-checksums.sh

# Verify a specific release
sha256sum -c release/checksums/RELEASE_ARTIFACTS_CHECKSUMS_<version>.txt
```
