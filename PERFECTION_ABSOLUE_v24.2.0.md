### 2. Null Safety

```typescript
// Pattern 1: Optional chaining + nullish coalescing
const value = object?.property ?? defaultValue;

// Pattern 2: Type guard

  // Safe to use value

// Pattern 3: Variable extraction

  // Safe to use extracted
```
