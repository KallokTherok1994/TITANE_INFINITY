# V9 Scope And UI Quality Goal

Scope:
- Confirm canonical post-merge state on MAIN
- Prove runtime desktop behavior with visual and interaction evidence
- Detect and classify any critical UI defect in scope
- Apply only safe, bounded recovery/fix when required

UI quality goal in scope:
- chat-input visible and usable
- chat-send visible and usable
- chat-message-content visible after send
- onboarding screen absent in runtime flow
- no IPC fallback path used for proof
- no critical overlay block preventing interaction
- layout not critically broken in captured frames
