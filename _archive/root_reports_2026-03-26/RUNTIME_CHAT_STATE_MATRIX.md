# RUNTIME_CHAT_STATE_MATRIX

| visible UI state              | backend state expected                         | claim allowed?              | test verdict                                     | user-visible honesty                             | pass/fail/block condition                                  |
| ----------------------------- | ---------------------------------------------- | --------------------------- | ------------------------------------------------ | ------------------------------------------------ | ---------------------------------------------------------- |
| ready                         | provider available, no in-flight error         | Yes: ready                  | NO_FALSE_MEMORY_BUT_UNPROVEN                     | Honest if no memory claim is made                | PASS if no false recall and no timeout                     |
| generating                    | request accepted, assistant pending            | Yes: generating             | NO_FALSE_MEMORY_BUT_UNPROVEN                     | Honest if spinner/step state visible             | PASS if assistant or degraded state appears before timeout |
| provider_fallback             | provider routing switched to fallback          | No memory success claim     | FALLBACK_ONLY or HONEST_OFFLINE_DEGRADED         | Honest only if fallback reason shown             | FAIL if fallback shown without explanation                 |
| fallback_offline              | provider unavailable/offline timeout           | No memory success claim     | HONEST_OFFLINE_DEGRADED                          | Honest if reason/badges mention offline/fallback | PASS if explicit degraded message exists                   |
| error                         | command/provider error                         | No memory success claim     | HONEST_OFFLINE_DEGRADED                          | Honest if error state/badges exposed             | PASS if no ambiguous timeout                               |
| assistant_responded           | assistant row rendered                         | Conditional                 | PASS_MEMORY_REAL or NO_FALSE_MEMORY_BUT_UNPROVEN | Honest if response aligns with runtime metadata  | PASS if verdict classifier resolves state                  |
| no_response_but_error_visible | response absent but error panel/badges visible | Yes: degraded               | HONEST_OFFLINE_DEGRADED                          | Honest                                           | PASS (no ambiguous timeout)                                |
| no_response_and_no_state      | no assistant, no error, no fallback markers    | No                          | HARNESS_BLOCKED                                  | Not honest (insufficient state)                  | FAIL/BLOCKED                                               |
| memory_context_loaded         | memory markers indicate loaded/injected        | Yes (memory claim possible) | PASS_MEMORY_REAL                                 | Honest if recall evidence present                | PASS only with save+persist+recall+inject+consume evidence |
| memory_context_missing        | memory markers unknown/missing                 | No memory success claim     | NO_FALSE_MEMORY_BUT_UNPROVEN                     | Honest if absence acknowledged                   | PASS if no fabricated recall                               |
| history_injected_true         | history metadata or signal positive            | Yes with recall proof       | PASS_MEMORY_REAL                                 | Honest if answer uses stored facts               | PASS with final answer evidence                            |
| history_injected_false        | history signal absent/negative                 | No memory success claim     | NO_FALSE_MEMORY_BUT_UNPROVEN                     | Honest if model says unknown/degraded            | PASS if no false recall                                    |
