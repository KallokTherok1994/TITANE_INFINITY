## 🎯 Key Decisions Made

### 1. E2E Detection Strategy
**Decision:** Implement multi-layer detection (webdriver + UA + localStorage)  
**Rationale:** Ensures robust detection across different test environments  
**Result:** 100% reliable E2E mode activation in tests

### 2. Wait Strategy in Tests
**Decision:** Replace setTimeout with locator.waitFor()  
**Rationale:** Removes timing-based flakiness, makes tests deterministic  
**Result:** Zero intermittent failures in final runs

### 3. Mock vs Real Backend
**Decision:** Use mock conversation engine in E2E mode  
**Rationale:** Eliminates Tauri dependency, speeds up tests, ensures isolation  
**Result:** Tests run in <5 seconds per test, 100% reliable

### 4. Error Handling
**Decision:** Graceful degradation for memory profiling failures  
**Rationale:** Tests continue even if evaluation context destroyed  
**Result:** Resilient test suite that handles edge cases
