PRODUCTION ISSUES RESOLVED
═════════════════════════════════════════════════════════════════════════════

ISSUE #1: "Erreur lors de l'appel à Ollama : Load failed"
──────────────────────────────────────────────────────────
Symptom:    User gets error when Ollama not pre-running
Root Cause: Only checks bundled binary path, no system fallback
Fix:        4-step auto-start mechanism (main.rs:625)
Details:
  • Check if already running on 127.0.0.1:11434
  • Try bundled binary (resources/ollama/ollama, ollama/ollama, bin/ollama)
  • Fall back to system `ollama` command
  • Display clear error with install instructions if failed
Result:     DEB/AppImage now auto-launches Ollama OR shows helpful error
Verification: ✅ Compiled | ✅ In artifacts

ISSUE #2: DevTools (F12) Not Working in PROD
──────────────────────────────────────────────
Symptom:    F12 key doesn't open Developer Tools
Root Cause: Hardcoded #[cfg(debug_assertions)] - only for DEV builds
Fix:        Runtime environment variable check (main.rs:854-867)
Details:
  Before: #[cfg(debug_assertions)] { main_window.open_devtools(); }
  After:  Check TITANE_DEVTOOLS env var at runtime
  Usage:  TITANE_DEVTOOLS=1 /usr/bin/titane-infinity
Result:     F12 now works in PROD when env variable set
Verification: ✅ Compiled | ✅ In artifacts

ISSUE #3: Configuration Not Persisting + Admin Undefined
───────────────────────────────────────────────────────
Symptoms:
  • Admin settings show "undefined"
  • User changes don't survive app restart
  • Governance parameters don't work
Root Cause: No default config values, no localStorage persistence
Fix:        Configuration system (ollama.ts:38-90)
Details:
  • DEFAULT_OLLAMA_CONFIG with sensible values
  • getOllamaConfig() with 3-tier fallback:
    1. Environment variables (OLLAMA_MODEL, OLLAMA_ENDPOINT)
    2. localStorage (persisted user settings)
    3. DEFAULT_OLLAMA_CONFIG (hardcoded defaults)
  • setOllamaConfig() saves to localStorage
Result:
  • Admin UI now shows proper values (not undefined)
  • Changes persist across app restarts
  • Environment variables can override everything
Verification: ✅ Compiled | ✅ In artifacts
