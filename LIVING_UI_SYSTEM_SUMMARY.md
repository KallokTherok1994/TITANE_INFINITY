---

### 2. **Visual Conductor**

`src/visual-engine/orchestrators/VisualConductor.ts`

**L'orchestrateur événementiel**

- 📡 Écoute événements OS
- 🎭 Traduit via Grammar
- 🎯 Gère priorités & conflits
- 📊 Monitoring latence/métriques
- 🔄 Queue asynchrone

**Flux** :

```
OS Event → Conductor → Grammar → Phenomena → Visual Engine → Render
```

**Résolution conflits** :

- Priority : Remplace moins prioritaire
- Merge : Fusionne similaires (moyenne pondérée)
- Queue : Attend libération

---

### 3. **UI Mode System**

`src/visual-engine/modes/UIModeManager.ts`

**Adaptation dynamique intelligente**

**5 Modes** :

- **AUTO** : Adaptatif intelligent (ajustement toutes les 2s)
- **MINIMAL** : Économie max (30 FPS, pas de particules/effets)
- **PERFORMANCE** : 60 FPS garanti (quality dynamique)
- **IMMERSIVE** : Effets max (density 1.0, quality high)
- **DEBUG** : États visibles (FPS, metrics, overlays)

**Mode AUTO — Intelligence** :

- FPS < 80% target → Réduction qualité
- FPS > 95% + CPU < 60% → Augmentation qualité
- Historique 20 derniers ajustements

---

### 4. **UI Layer Hierarchy**

`src/visual-engine/hierarchy/UILayerManager.ts`

**Architecture en 6 couches**

**Layers** :

- **Layer 0** : Background (z:0)
- **Layer 1** : Visual Core (z:10)
- **Layer 2** : Primary Panels (z:100) — Chat, Memory, DevTools
- **Layer 3** : Secondary Panels (z:200) — Governance, SelfHealing, etc.
- **Layer 4** : Overlays (z:1000) — Modals, Notifications
- **Layer 5** : Debug (z:9999) — FPS, State Inspector

**15 Types de Panels définis** avec :

- Rôle sémantique ("Cœur conversationnel", "Système immunitaire")
- Position par défaut
- Comportements (collapsible, draggable, resizable)
- isCore (essentiel au système)

## 🎓 CONCEPTS CLÉS À RETENIR

### 1. **Langage Sémiotique**

L'UI n'affiche pas "des effets". Elle **traduit** des états internes en phénomènes **signifiants**.

### 2. **Orchestration Événementielle**

Le Conductor n'exécute pas directement. Il **reçoit**, **traduit**, **priorise**, **orchestre**.

### 3. **Adaptation Intelligente**

Le système **observe** (FPS, CPU), **décide** (réduire/augmenter), **ajuste** (config), **apprend** (historique).

### 4. **Hiérarchie Organique**

Les couches reflètent l'**anatomie** du système :

- Fond (contexte)
- Noyau (identité)
- Primaires (fonctions vitales)
- Secondaires (systèmes support)
- Overlays (interactions)
- Debug (introspection)
