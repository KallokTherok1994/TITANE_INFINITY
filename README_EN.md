## 🚀 60-SECOND START

### 1️⃣ **Install**

```bash
# Linux
wget https://releases.titane.dev/titane-stable.AppImage
chmod +x titane-stable.AppImage
./titane-stable.AppImage

# macOS
brew tap titane/tap
brew install titane

# Windows
winget install titane-stable
```

### 2️⃣ **Launch**

Click the app icon → TITANE loads (< 2 seconds)

### 3️⃣ **First Conversation**

```
You: "Hello! What can you do?"

TITANE: "Welcome! I'm TITANE∞.
I can:
✅ Converse naturally
✅ Analyze files & images
✅ Remember your preferences
✅ Help with coding, writing, research, brainstorming...
What's your first question?"
```

**Done!** You're ready. 🎉
