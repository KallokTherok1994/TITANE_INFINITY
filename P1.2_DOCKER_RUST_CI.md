## 📋 OBJECTIF

Permettre l'exécution des tests backend Rust en CI GitHub Actions via Docker avec toutes les dépendances système nécessaires (Tauri, GTK, WebKit).

---

## ❌ PROBLÈME INITIAL

**Symptôme:**
```bash
$ cargo test
error: failed to run custom build command for `glib-sys v0.x.x`
  
  --- stderr
  Package glib-2.0 was not found in the pkg-config search path.
```

**Cause Racine:**
- CI GitHub Actions Ubuntu ne contient pas les bibliothèques système Tauri
- Dépendances manquantes: `libwebkit2gtk`, `libgtk-3`, `librsvg2`, etc.
- Tests Rust backend ne peuvent pas compiler en CI

**Impact:**
- ❌ Impossible de valider backend Rust en CI
- ❌ Pas de détection précoce bugs Rust
- ⚠️ Risque regression backend non détectée

---

## ✅ SOLUTION IMPLÉMENTÉE

### Architecture

```
GitHub Actions
    ↓
Docker Container (rust:1.83-slim)
    ↓
Installation Dépendances Système
    ├─ libwebkit2gtk-4.1-dev
    ├─ libgtk-3-dev
    ├─ libayatana-appindicator3-dev
    ├─ librsvg2-dev
    ├─ patchelf
    ├─ libssl-dev
    ├─ pkg-config
    └─ build-essential
    ↓
Cargo Check + Test + Clippy
    ↓
Rapports & Artifacts
```

### Workflow Créé

**Fichier:** `.github/workflows/rust-docker.yml`

**Déclencheurs:**
- ✅ `workflow_dispatch` — Manuel (test immédiat)
- ✅ `push` vers MAIN/dev/stable-runtime
- ✅ `pull_request` vers MAIN
- ✅ Seulement si fichiers `src-tauri/**` modifiés (optimisation)

**Jobs:**

**1. test-rust-docker**
```yaml
runs-on: ubuntu-latest
container: rust:1.83-slim

steps:
  1. Checkout code
  2. Install system deps (apt-get)
  3. Cache Cargo registry
  4. Cache Cargo build
  5. cargo check
  6. cargo test
  7. cargo clippy
  8. Generate report
  9. Upload artifacts
```

**Durée Estimée:** 8-12 minutes
- Installation deps: ~2 min (cachée après 1ère fois)
- Cargo build: ~5 min (cachée)
- Tests: ~3 min

## 🎯 FONCTIONNALITÉS

### 1. Installation Dépendances Automatique

```bash
apt-get install -y \
  libwebkit2gtk-4.1-dev \  # WebView Tauri
  libgtk-3-dev \            # Interface GTK
  libayatana-appindicator3-dev \  # Indicateurs système
  librsvg2-dev \            # Rendu SVG
  patchelf \                # Patch binaires
  libssl-dev \              # SSL/TLS
  pkg-config \              # Configuration packages
  build-essential           # Compilateurs C/C++
```

### 2. Cache Intelligent

**Cargo Registry Cache:**
- Path: `~/.cargo/registry`, `~/.cargo/git`
- Clé: OS + hash Cargo.lock
- Restauration: Partielle si hash change
- **Gain:** ~1-2 min par build

**Cargo Build Cache:**
- Path: `src-tauri/target`
- Clé: OS + hash Cargo.lock
- **Gain:** ~3-5 min par build

### 3. Validation Complète

**Étape 1: `cargo check`**
- Vérifie compilation sans générer binaire
- Rapide (~30s après cache)
- Détecte erreurs syntaxe Rust

**Étape 2: `cargo test`**
- Exécute tous tests unitaires/intégration
- Avec RUST_BACKTRACE=1 pour debugging
- Génère rapport détaillé

**Étape 3: `cargo clippy`**
- Linter Rust avancé
- Détecte idioms non-idiomatiques
- Continue même si warnings (non-bloquant)

### 4. Rapports & Artifacts

**Test Summary:**
- Généré dans `src-tauri/test-summary.md`
- Upload comme artifact (30 jours rétention)
- Consultable dans Actions UI

## 🐛 TROUBLESHOOTING

### Tests Échouent

**1. Vérifier Logs:**
```bash
# Dans Actions tab, ouvrir workflow failed
# Cliquer sur job "test-rust-docker"
# Consulter step "Run Rust Tests"
```

**2. Reproduire Localement:**
```bash
# Utiliser même image Docker
docker run -it --rm -v $(pwd):/workspace -w /workspace rust:1.83-slim bash

# Installer deps
apt-get update && apt-get install -y libwebkit2gtk-4.1-dev ...

# Tester
cd src-tauri
cargo test
```

### Cache Ne Fonctionne Pas

**Invalider cache:**
1. Aller Settings → Actions → Caches
2. Supprimer caches concernés
3. Re-run workflow

### Timeout Build

**Augmenter timeout:**
```yaml
jobs:
  test-rust-docker:
    timeout-minutes: 30  # Défaut: 360 min
```
