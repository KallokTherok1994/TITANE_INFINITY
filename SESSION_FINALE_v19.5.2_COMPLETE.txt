1. COGNITIVE METADATA PERSISTENCE (Phase 2 improvement)
   
   Issue:
     Lors du reload d'une conversation, les métadonnées cognitives
     sont réinitialisées aux valeurs par défaut.
   
   Champs affectés:
     - intention: Toujours "Question"
     - emotion: EmotionState::default()
     - tags: Vec vide
     - summary: String vide
     - memory_effect: MemoryEffect::New
     - memory_layers: Default
     - links_to_contexts: Vec vide
     - provider_used: "unknown"
     - latency_ms: 0
   
   Impact:
     Minimal - Messages et context préservés correctement
     L'IA peut continuer les conversations normalement
   
   Solution future:
     Enrichir MemoryEntry.metadata (Option<serde_json::Value>)
     avec toutes les métadonnées cognitives
   
   Priority:
     Phase 2 enhancement (non-blocking)
