## What is TITANE∞?

TITANE∞ is a **desktop application** built with Tauri (Rust + React) that lets you interact with AI models (OpenAI, Claude, Gemini, Ollama) through a unified interface.

**What TITANE∞ is:**
- A Tauri desktop application (Linux, Windows, macOS) — PROVEN
- A unified frontend for multiple AI providers — PROVEN
- An app with hierarchical conversational memory (STM/MTM/LTM) — PARTIAL
- An app with voice/TTS mode — PROVEN

**What TITANE∞ is NOT:**
- It is NOT a fully local or offline-first application — network connectivity is required for cloud providers (OpenAI, Claude, Gemini)
- It is NOT "100% local" — this description in older documents is obsolete (LEGACY)
- It is NOT a browser-only web app — the production runtime is Tauri desktop and the current public Linux binary stream is `v30.0.0`
