## 🎯 Qu'est-ce que TITANE∞ ?

TITANE∞ est un **assistant IA local** de nouvelle génération qui fonctionne **100% sur votre machine**. Aucune donnée n'est envoyée dans le cloud — vos conversations restent privées et sécurisées.

### ✨ Caractéristiques Principales

- 🔒 **100% Local** : Toutes vos données restent sur votre ordinateur
- 🧠 **Multi-Moteurs IA** : OpenAI, Claude, Gemini, modèles locaux (Ollama)
- 💾 **Mémoire Hiérarchique** : L'IA se souvient de vos conversations (court, moyen, long terme)
- 🎙️ **Mode Audio** : Parlez avec l'IA en temps réel
- ⚡ **Ultra-Rapide** : Architecture Rust + React optimisée
- 🎨 **Interface Moderne** : Design minimaliste et intuitif
- 🔧 **DevTools Intégrés** : Monitoring, debugging, performance

## 🚀 Démarrage Rapide

### 1. Installation

Téléchargez la dernière version pour votre système :
- **Windows** : `TITANE-Infinity-19.4.3-setup.exe`
- **macOS** : `TITANE-Infinity-19.4.3.dmg`
- **Linux** : `TITANE-Infinity-19.4.3.AppImage`

Double-cliquez sur le fichier téléchargé et suivez les instructions.

👉 **[Guide d'Installation Détaillé](./installation.md)**

### 2. Premier Lancement

1. Lancez **TITANE∞**
2. Configurez votre clé API (OpenAI, Claude, ou Gemini)
3. Commencez votre première conversation !

## 🔐 Sécurité & Confidentialité

### Local-First Architecture

- ✅ **Aucune télémétrie** : Nous ne collectons aucune donnée
- ✅ **Chiffrement AES-256** : Toutes vos données sont chiffrées
- ✅ **Clés API sécurisées** : Stockées dans un coffre-fort chiffré
- ✅ **Code Open Source** : Auditable et transparent

### Contrôle Total

- Vous choisissez quel moteur IA utiliser
- Vous gérez vos propres clés API
- Vous décidez ce qui est sauvegardé
- Vous pouvez exporter/supprimer toutes vos données
