# MERMAID Dev Preview (Optionnel)

## Objectif

Prévisualiser les diagrammes Mermaid pendant l'édition dans VS Code, sans impact build/runtime.

## Recommandation VS Code (optionnelle)

- Utiliser les capacités natives Markdown Preview de VS Code.
- Optionnel: extension Mermaid/Markdown pour confort d'édition local.

## Gouvernance

- Cette prévisualisation est purement locale et optionnelle.
- Aucune dépendance Mermaid ne doit être ajoutée au frontend/runtime.
- Aucun CDN, aucun fetch externe, aucun rendu in-app.
