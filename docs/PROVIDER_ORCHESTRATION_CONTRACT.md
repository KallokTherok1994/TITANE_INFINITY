# Provider Orchestration Contract (P3_META_V1)

**Purpose:** Define the canonical, binding contract for provider orchestration metadata and offline semantics.
**Scope:** IPC responses for `conversation_generate` and any equivalent provider routing path.
**Ring:** 0 (governance only)

## Definitions

- **provider_id**: Stable provider identifier string (e.g., `local`, `ollama`, `gemini`, `openai`, `claude`).
- **provider_class**: `local` | `remote` | `hybrid`.
- **mode**: `LOCAL` | `REMOTE` | `OFFLINE` | `CACHED` | `ERROR`.
- **reason_code**: Canonical enum defined in [PROVIDER_REASON_CODES](PROVIDER_REASON_CODES.md).

## Meta Invariants (P3_META_V1)

- `meta` MUST be present on every IPC success response.
- `meta` SHOULD be present on IPC error responses when possible.
- The Rust backend is the runtime source of truth. UI must not infer provider/mode from DOM or errors.

### Required Fields (v1)

- `provider_used` (string)
- `provider_class` (`local`|`remote`|`hybrid`)
- `mode` (`LOCAL`|`REMOTE`|`OFFLINE`|`CACHED`|`ERROR`)
- `reason_code` (enum)
- `latency_ms_total` (u64)
- `timeout_ms` (u64)
- `retries` (u32)
- `attempts[]` (array)
- `network_used` (bool)
- `cache_hit` (bool)
- `policy` (string or enum)

## attempts[] Schema (v1)

Each attempt MUST include:
- `provider_id` (string)
- `provider_class` (`local`|`remote`|`hybrid`)
- `start_ts` (u64, optional)
- `latency_ms` (u64)
- `outcome` (`success`|`failure`|`timeout`)
- `reason_code` (enum)
- `network_used_attempt` (bool)

## Offline Semantics

- `FORCE_LOCAL_PROVIDER=1` is **not** offline. It is a local policy override.
- `OFFLINE_SIM=1` (test-only) **forces offline fallback**:
  - `mode=OFFLINE`
  - `reason_code=FALLBACK_OFFLINE`
  - `network_used=false`
  - UI shows offline tags

## Local-first and network_used

- `network_used=true` only if the request reaches the public internet.
- Loopback (e.g., `127.0.0.1`, `localhost`) is **local** and does not set `network_used`.
- `ollama` is classified as `local` when accessed via loopback.

## Allowlist & Enforcement

- If an allowlist rule denies a route, return `reason_code=ALLOWLIST_DENIED` and `network_used=false`.
- UI must render the reason based on `reason_code`, not on inference.

## Source of Truth

- Runtime truth is generated by Rust (Tauri backend) and exposed via IPC.
- Frontend uses `meta` directly; no DOM parsing or heuristic inference.

## Versioning

- Contract version: **P3_META_V1**.
- Breaking changes require a new version with a migration plan and addendum entry.
