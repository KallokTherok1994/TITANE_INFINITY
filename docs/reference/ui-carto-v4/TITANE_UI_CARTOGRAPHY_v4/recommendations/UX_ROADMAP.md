# UX Roadmap (pragmatique)

## Objectif
Réduire la charge cognitive sans perdre la puissance.

### 1) Modes d’affichage
- **Simple** : 3 KPIs + 3 actions clés
- **Avancé** : tout le cockpit (actuel)

### 2) Progressive disclosure
- Les dashboards “ultimate optimization” et “dev tools” passent derrière un toggle “advanced”.

### 3) Cohérence terminologique
- Uniformiser : “Santé”, “Score”, “Statut”.
- Remplacer “UNKNOWN” par :
  - “Données non disponibles” + pourquoi + bouton “Réessayer”.

### 4) Feedback systématique
- Sur toute action : toast + trace id + bouton “ouvrir logs”.

### 5) Accessibilité minimale
- Contrastes (déjà travaillé)
- Focus states sur tabs & boutons
- Navigation clavier pour chat & dashboards
