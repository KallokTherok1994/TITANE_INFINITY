# TITANE — Vue d’ensemble (module)

## But
Donner l’état des modules TITANE (chat, mémoire, identité, audio, etc.) et l’accès rapide aux fonctions clés.

## Attendus UI
- Cards par module avec :
  - statut (ok/degraded/down)
  - métriques (latence, erreurs, taille mémoire)
  - actions (open, repair, export)

## Risques
- Si non implémenté : afficher un placeholder clair (pas “UNKNOWN” silencieux).
