# DEV — Command Center

## But
Vue agrégée des “centres” moteurs : system, governance, design, audio, evolution, orchestration.

## UI observée
Cards :
- System Center (Core)
- Governance Center (Security)
- Design Center (UI)
- Audio Center (UI)
- Evolution Center (Cognitive)
- Orchestration Center (Cognitive)

Chaque card :
- Santé (%)
- Compteur engines (X / Y engines)

## Interactions recommandées
- Click card → page détail du centre (logs, actions, métriques).
- Actions rapides : Restart / Sync / Repair / Open logs.

## Risques
- Valeurs “UNKNOWN” si status non chargé.
- Conflits de version si centres init différemment.
