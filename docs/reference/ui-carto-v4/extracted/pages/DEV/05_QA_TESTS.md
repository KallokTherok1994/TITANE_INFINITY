# DEV — Q&A Tests

## But
Piloter les suites de tests et visualiser l’état qualité.

## UI observée
- KPI : couverture tests (%), moniteurs actifs, hardening “strict”
- Cards :
  - Tests Unitaires
  - Tests Integration
  - Tests E2E
  - Tests Performance
- Chaque card : compteurs (pass/fail/skip?) + bouton “Exécuter”

## Recommandations
- Afficher dernier run : timestamp, commit, durée.
- Bouton “Voir rapport” + export.
- En cas d’échec : lien direct vers log + diff si snapshot.
