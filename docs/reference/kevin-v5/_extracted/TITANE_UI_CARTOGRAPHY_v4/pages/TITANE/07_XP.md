# TITANE — XP

## Statut
- Pill **XP** visible.

## Rôle produit (cible)
Suivi de progression et de maîtrise :
- compétences (modes, outils),
- habitudes (routines),
- milestones (beta, stable),
- feedback (qualité réponses, latence, erreurs).

## UI attendue
- Tableau de bord (badges, score, streaks).
- Historique : sessions, achievements.
- Actions : exporter, reset, annotations.

## Risques
- Gamification non alignée → surcharge cognitive.
- Mesures NaN/UNKNOWN (comme STATS) → bruit.
- Gamification non alignée → bruit.
- Scores NaN/UNKNOWN si données absentes.

## Tests
- XP avec dataset vide.
- XP avec dataset volumineux.
