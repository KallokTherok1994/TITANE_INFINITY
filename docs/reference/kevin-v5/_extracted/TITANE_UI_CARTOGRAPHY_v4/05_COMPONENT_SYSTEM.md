# Système de composants UI

## Patterns dominants
- Cards dashboard (KPI) : titre + valeur + badge + action.
- Tabs/pills : navigation secondaire.
- Boutons CTA : actions système (Exécuter, Acquitter, Tester...).
- Overlays : Boot Beacon, Console Monitor.
- Widget flottant : Cognitive Layout.

## Tokens (thème)
- Fond sombre + accents néon.
- Bordures glow.
