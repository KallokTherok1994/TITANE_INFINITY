### 🔄 Workflow Mémoire Complet

```
1. User sends message
   ↓
2. Frontend: useChatMemory.saveMessage(message)
   ↓
3. chatMemoryCompactor.addMessageToMode(mode, message)
   ↓
4. (Optional) Backend sync: invoke('memory_set', { key, value })
   ↓
5. MemoryStorage.save_conversation(conversation)
   ↓
6. Encryption + Write to disk
   ↓
7. Update index.json.enc
   ↓
8. Stats updated in useChatMemory
```
