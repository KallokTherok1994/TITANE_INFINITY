### 3. UI Mode System
`src/visual-engine/modes/UIModeManager.ts` (580 lines)

Système adaptatif de modes visuels avec intelligence automatique.

**5 Modes** :
- **AUTO** : Adaptatif (ajustement toutes les 2s selon FPS/CPU)
- **MINIMAL** : Économie max (30fps, pas particules/effets)
- **PERFORMANCE** : 60fps garanti (quality dynamique)
- **IMMERSIVE** : Effets max (density 1.0, quality high)
- **DEBUG** : États visibles (FPS, metrics, overlays)

**Mode AUTO Intelligence** :
- FPS < 80% target → Réduction qualité
- FPS > 95% + CPU < 60% → Augmentation qualité
- Historique 20 derniers ajustements

import {
  VisualConductor,

  UILayerManager,
  VisualSemanticGrammar,
  EngineState,

  UIMode,

// Initialisation
const conductor = new VisualConductor({ debug: true });
const modeManager = new UIModeManager(UIMode.AUTO);

  type: 'engine_state_change',
  engine: EngineState.SELF_HEALING,

  timestamp: Date.now(),

// Mode adaptatif
modeManager.setMode(UIMode.IMMERSIVE);

// Panels
layerManager.showPanel(PanelType.GOVERNANCE);
