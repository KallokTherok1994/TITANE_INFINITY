## 🚀 How to Use DevTools

### Method 1: Automatic (Debug Build)
```bash
pnpm run tauri:dev
```
**→ DevTools open automatically** ✅

### Method 2: Keyboard Shortcuts
Once the app is running:
- Press **F12**
- Or press **Ctrl+Shift+I**

### Method 3: Emergency Fallback Button
If the UI is black and nothing works:
- Look for the **red "🔧 DEBUG" button** in top-right corner
- Click it to force-open DevTools

## 🔍 Debugging Black Screen

With DevTools now active, follow these steps:

### Step 1: Check Console Tab
Look for:
- ❌ `Failed to load module`
- ❌ `Uncaught TypeError`
- ❌ `404 Not Found`
- ❌ CSP violations

### Step 2: Check Network Tab
Verify:
- ✅ `main.tsx` loads successfully
- ✅ `titane-v12.css` loads
- ✅ All imports return 200 OK

### Step 3: Check Elements Tab
Verify:
- ✅ `<div id="root">` exists
- ✅ React components are mounted
- ✅ CSS is applied

### Step 4: Check Sources Tab
Verify:
- ✅ Source maps are loaded
- ✅ You can see TypeScript/JSX code
- ✅ Breakpoints can be set

## 🚨 Common Black Screen Causes

| Issue | Solution |
|-------|----------|
| **CSP too restrictive** | ✅ Already relaxed in tauri.conf.json |
| **Missing dist files** | Run `pnpm run build` |
| **Wrong distDir path** | Already set to `../dist` |
| **React error on mount** | Check ErrorBoundary in console |
| **Missing CSS** | Check Network tab for 404s |
| **WebView crash** | Check `journalctl -xe \| grep titane` |

## 🔥 Production Build

To enable DevTools in production build, modify `main.rs`:

```rust

if let Some(window) = app.get_webview_window("main") {
    window.open_devtools();
}
```
