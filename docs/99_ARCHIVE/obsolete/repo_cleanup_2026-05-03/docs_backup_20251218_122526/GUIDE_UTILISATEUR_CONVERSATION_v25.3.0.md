## 🚀 DÉMARRAGE RAPIDE

### Accéder à la Conversation

1. Ouvrez TITANE∞
2. Cliquez sur l'onglet **💬 Conversation**
3. L'interface de chat s'affiche

---

## 💬 UTILISER LE CHAT

### Envoyer un Message

1. Tapez votre message dans la zone de texte en bas
2. Appuyez sur **Entrée** ou cliquez sur **📤 Envoyer**
3. TITANE répond automatiquement

**Astuce:** Utilisez **Shift + Entrée** pour une nouvelle ligne sans envoyer

### Sélectionner un Provider IA

En haut à gauche, choisissez parmi:

- **✨ Gemini** - Google AI (cloud)
- **🦙 Ollama** - LLM local
- **🤖 OpenAI** - GPT (cloud)
- **🧠 Claude** - Anthropic (cloud)

---

## 🎯 MODES CONVERSATIONNELS

### Modes Prédéfinis

Sélectionnez un mode dans le menu déroulant:

| Mode               | Icône | Utilisation               |
| ------------------ | ----- | ------------------------- |
| **Normal**         | 💬    | Conversation standard     |
| **Brainstorming**  | 💡    | Idéation et créativité    |
| **Synthèse**       | 📝    | Résumé et analyse         |
| **Planification**  | 📋    | Stratégie et organisation |
| **Journal**        | 📔    | Réflexion personnelle     |
| **Debug Cognitif** | 🔧    | Analyse système           |

### Créer un Mode Personnalisé

1. Cliquez sur **⚙️** (icône Mode Builder)
2. Décrivez votre mode ou choisissez un template
3. Cliquez sur **✨ Générer avec IA**
4. Configurez:
   - Nom du mode
   - Icône (24 choix)
   - Description
   - Instructions (system prompt)
   - Température (créativité)
5. **Aperçu** pour vérifier
6. **✅ Sauvegarder**

Votre mode apparaît maintenant dans la liste!

## 🔊 FONCTIONS AUDIO

### Text-to-Speech (Lecture)

1. Cliquez sur **🔊** pour activer
2. Les réponses de TITANE seront lues à voix haute
3. Cliquez sur **🔇** pour désactiver

### Speech-to-Text (Dictée)

1. Cliquez sur **🎤** (microphone)
2. Parlez (le bouton devient rouge 🔴)
3. Votre parole est transcrite automatiquement
4. Cliquez à nouveau pour arrêter

## 🛠️ OUTILS AVANCÉS

### Santé du Système

- **✅** = Système optimal
- **⚠️** = Anomalies détectées (auto-réparation en cours)
- **🚨** = État critique

Cliquez pour rafraîchir le diagnostic.

### Effacer l'Historique

1. Cliquez sur **🗑️**
2. Confirmez
3. L'historique est effacé (nouveau chat)

## ❓ DÉPANNAGE

### Le chat ne répond pas

1. Vérifiez l'icône santé (**✅**)
2. Essayez un autre provider
3. Cliquez sur **🗑️** pour nouveau chat

### Pas de son (TTS)

1. Vérifiez que **🔊** est activé
2. Vérifiez le volume de votre ordinateur
3. Essayez un autre navigateur

### Mode personnalisé non sauvegardé

1. Vérifiez que tous les champs sont remplis
2. Cliquez bien sur **✅ Sauvegarder**
3. Rafraîchissez la page

---

## 🎯 MEILLEURES PRATIQUES

### Pour des Réponses Optimales

✅ **Faire:**

- Soyez clair et précis
- Utilisez le mode approprié
- Donnez du contexte si nécessaire

❌ **Éviter:**

- Messages trop vagues
- Mode inadapté (ex: Debug pour créativité)
- Messages trop longs (> 1000 caractères)

### Organisation

- Créez des modes pour vos tâches récurrentes
- Utilisez les tags pour retrouver des conversations
- Effacez l'historique régulièrement
