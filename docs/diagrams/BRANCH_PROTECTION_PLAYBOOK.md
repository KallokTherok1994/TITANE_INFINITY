# Branch Protection Playbook (Mermaid Governance)

## Scope

Apply to branch: MAIN

## Checklist

- Protect branch: MAIN
- Require status checks to pass before merging
  - Mermaid Governance / mermaid_governance (required)
- Require branches to be up to date before merging (recommended)
- Require linear history (recommended)
- Restrict force pushes (recommended)
- Require pull request reviews (optional, team policy)

## Notes

GitHub settings are not enforced by commits. Apply these in repository settings.
