# Mermaid Zero-Touch Commitment

À partir de V14 :

- Aucun commit Mermaid sans changement système réel
- Aucun commit Mermaid pour “amélioration”
- Aucun commit Mermaid pour “propreté”
- Aucun commit Mermaid pour “optimisation”

Mermaid n’est plus un chantier.
Mermaid est une infrastructure scellée.
