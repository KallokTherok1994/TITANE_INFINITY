# Mermaid Minimalism Note

Mermaid est un outil de gouvernance.
Pas un outil de demonstration.

Ajouter un diagramme doit etre exceptionnel.
Toute extension doit prouver :

- Valeur strategique
- Reduction de risque
- Pas de complexite cumulative

## Refuse to expand without impact

Refuser toute expansion sans impact reel et prouve.
