### �🔒 RÈGLE #1 : TITANE∞ = 100% TAURI UNIQUEMENT

**INTERDICTIONS ABSOLUES (JAMAIS, EN AUCUN CAS) :**

```bash
❌ vite preview (serveur HTTP standalone)
❌ serve dist (serveur HTTP standalone)
❌ python3 -m http.server (serveur HTTP standalone)
❌ Tout serveur HTTP/HTTPS standalone accessible
❌ Exposer l'application via HTTP hors Tauri wrapper
```

**MÉTHODES AUTORISÉES UNIQUEMENT :**

```bash
✅ tauri dev (développement avec hot-reload)
✅ tauri build (production)
✅ cargo build --release (backend)
✅ npm run dev (si = tauri dev dans package.json)
```

**⚠️ CLARIFICATION IMPORTANTE - Mode Développement:**

Le mode `tauri dev` démarre un serveur Vite local (http://localhost:5173) pour le hot-reload, MAIS:

- Ce serveur est **UNIQUEMENT accessible** par le Tauri WebView
- Il n'est **PAS exposé** comme serveur HTTP standalone
- L'application reste **100% native** via Tauri
- En production (`tauri build`), **AUCUN serveur HTTP** n'est utilisé

Cette configuration **respecte l'esprit de la règle**: pas de serveur HTTP standalone accessible depuis l'extérieur. Tout passe par l'encapsulation Tauri.

**ARCHITECTURE OBLIGATOIRE :**

```
Mode Développement (tauri dev):
┌────────────────────────────────────────┐
│ TITANE∞ (Application Native Tauri)     │
│  └─ Tauri WebView (wrapper natif)     │
│      └─ Vite Dev Server (interne)     │  ← http://localhost:5173
│          └─ React App (hot-reload)    │     (accessible Tauri only)
└────────────────────────────────────────┘

Mode Production (tauri build):
┌────────────────────────────────────────┐
│ TITANE∞ (Application Native Tauri)     │
│  └─ Tauri WebView (wrapper natif)     │
│      └─ Fichiers statiques (dist/)    │  ← Pas de serveur HTTP
│          └─ React App (optimisé)      │
└────────────────────────────────────────┘

= 100% APPLICATION NATIVE dans les deux cas
```
