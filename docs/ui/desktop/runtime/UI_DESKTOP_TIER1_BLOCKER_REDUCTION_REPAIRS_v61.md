### R1 — IPC Command Correction: EXPERIENCE

**Problem**: v60 spec for EXPERIENCE attempted IPC command `performance_get_metrics`, which does not exist in the Rust command registry.

**Fix**: v61 documentation records the correct command. v62 spec will use `experience_get_state`.

### R4 — Honest Classification for WDIO Browser Context

**Problem**: v60 failed AGENT_CHAT and EXPERIENCE with BLOCKED_BY_RUNTIME because IPC was attempted in a context where it cannot work. The classification did not distinguish between "IPC failed" (backend error) and "IPC not available" (test context constraint).

**Fix**: v61 uses DOM-based evidence instead of IPC. Classification is:
- `DEGRADED_WITH_UI_PROOF`: UI renders, IPC not confirmed (honest about test context)
- `GUARDED_WITH_UI_PROOF`: UI renders + governance confirmed, no IPC needed

This is semantically correct — the production app with a running Tauri binary DOES serve these pages correctly. The test context limitation is documented, not hidden.
