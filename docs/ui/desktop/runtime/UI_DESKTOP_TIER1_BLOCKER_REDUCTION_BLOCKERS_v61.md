## Residual Blockers After v61

These blockers persist after v61 promotion. They are classified as **honest, expected limitations** of the WDIO browser test context. They are NOT regressions — the production app serves these pages correctly.

---

### B1 — IPC Bridge Not Available in WDIO Browser Context

**Scope**: ALL 4 modules (AGENT_CHAT, EXPERIENCE, RESEARCH, CLOUD)  
**Symptom**: `window.__TAURI__` is undefined → `NO_TAURI_INVOKE` for all `browser.execute()` IPC calls  
**Root cause**: `TITANE_ENFORCE_BINARY_FRESHNESS=0` bypasses Tauri binary launch; tauri-driver does not inject IPC bridge  
**Classification**: `BACKEND_SERVICE_NOT_INITIALIZED` (test context, not production bug)  
**Resolution**: v62 — run E2E with full Tauri binary (TITANE_ENFORCE_BINARY_FRESHNESS=1, binary compiled)  
**Blocker level**: LOW (known, documented, not a regression)  

---

### B2 — EXPERIENCE IPC Command Mismatch (v60 Artifact)

**Scope**: EXPERIENCE module v60 records  
**Symptom**: v60 attempted `performance_get_metrics` which doesn't exist  
**Root cause**: Wrong command identified during v60 spec authoring  
**Fix in v61**: Documented the correct command (`experience_get_state` in mock_commands.rs)  
**Remaining**: v60 artifact contains incorrect command — NOT patched (append-only policy)  
**Classification**: DOCUMENTATION_CORRECTED — v60 artifact is historical, not overwritten  
**Resolution**: v62 spec uses correct command  

---

### B3 — RESEARCH: No Dedicated IPC Command

**Scope**: RESEARCH module  
**Symptom**: Research does not have a specific Tauri IPC command; results come from a network call routed through the One Door gateway  
**Root cause**: Design choice — research is a web search feature, not a local state feature  
**Classification**: `GOVERNED_NETWORK` — requires `TITANE_RESEARCH_NETWORK=sandbox` environment  
**Resolution**: v62 — set up controlled search sandbox environment + verify One Door routing  
**Blocker level**: MEDIUM (needs specific test environment setup)  

---

### B4 — CLOUD: Safe Sandbox Not Configured for Live Sync

**Scope**: CLOUD module  
**Symptom**: Cloud sync mutations (upload/download) require a safe sandbox path; no sandbox configured for E2E  
**Root cause**: Cloud sync touches external services (S3-compatible vault); no mock/sandbox configured  
**Classification**: `SAFE_SANDBOX_NOT_CONFIGURED`  
**Resolution**: v62 — configure mock vault endpoint (e.g. MinIO local) + sandbox environment  
**Blocker level**: MEDIUM (requires infrastructure setup)
