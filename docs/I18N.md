# Internationalization (i18n) - TITANE

## Supported Languages

- 🇫🇷 Français (default)
- 🇬🇧 English

## Setup

Dependencies added:

```json
{
  "i18next": "^23.7.0",
  "react-i18next": "^13.5.0",
  "i18next-browser-languagedetector": "^7.2.0"
}
```

## Usage

```tsx
import { useTranslation } from 'react-i18next';

function Component() {
  const { t, i18n } = useTranslation();

  return (
    <div>
      <h1>{t('app.name')}</h1>
      <p>{t('errors.message_too_long', { max: 100000 })}</p>

      <select onChange={e => i18n.changeLanguage(e.target.value)}>
        <option value="fr">Français</option>
        <option value="en">English</option>
      </select>
    </div>
  );
}
```

## Adding New Translations

1. Add keys to `src/i18n/locales/fr.json`
2. Add keys to `src/i18n/locales/en.json`
3. Use `t()` function in components

## Date/Number Formatting

```typescript
import { format } from 'date-fns';
import { fr, enUS } from 'date-fns/locale';

const localeMap = { fr, en: enUS };
format(date, 'PPP', { locale: localeMap[i18n.language] });
```
