## 🎯 Comment utiliser ces Super Prompts

### Dans GitHub Copilot Chat (VS Code)

1. Ouvrir le panneau **Copilot Chat** (`Ctrl+Alt+I` ou via la sidebar)
2. Copier-coller le contenu du super prompt
3. Utiliser `@workspace` en préfixe si nécessaire
4. Laisser Copilot analyser et générer le code
5. Reviewer et appliquer les modifications suggérées

### Bonnes pratiques

- ✅ **Un super prompt à la fois** : ne pas mélanger plusieurs super prompts dans une même session
- ✅ **Commit entre chaque** : commit après chaque super prompt réussi pour isoler les changements
- ✅ **Review attentif** : toujours lire et comprendre le code généré avant de l'appliquer
- ✅ **Test immédiat** : tester après chaque application (build, lint, tests unitaires)
- ⚠️ **Backup avant** : git stash ou branche séparée si modifications massives
