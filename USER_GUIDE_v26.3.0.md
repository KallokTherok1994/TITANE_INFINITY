# TITANE∞ User Guide v26.3.0

**Welcome to TITANE∞** - Your local-first AI companion

## 🚀 Quick Start

### Installation

#### Option 1: AppImage (Recommended)
```bash
# Download and run
chmod +x TITANE-Infinity_26.3.0_amd64.AppImage
./TITANE-Infinity_26.3.0_amd64.AppImage
```

#### Option 2: DEB Package
```bash
# Install system-wide
sudo dpkg -i TITANE-Infinity_26.3.0_amd64.deb
titane-infinity
```

#### Option 3: From Source
```bash
# Clone repository
git clone https://github.com/KallokTherok1994/TITANE_INFINITY.git
cd TITANE_INFINITY
./launch-titane.sh
```

## 🆘 Troubleshooting

### Common Issues

**Application won't start**
- Ensure you have required dependencies
- Check system requirements
- Verify file permissions (chmod +x)

**Slow performance**
- Close other resource-intensive applications
- Check available memory (minimum 4GB)
- Consider hardware acceleration options

**AI responses are slow**
- This is normal for local processing
- Consider upgrading hardware for better performance
- Adjust model settings for speed vs quality balance
