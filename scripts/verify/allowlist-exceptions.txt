# command
#   Reason: Generic stub name — never invoked in frontend code.

#           an unspecified "command" handler, which is a footgun.

#   Reason: Even as a Rust stub (returns degraded JSON), whitelisting a

#           devSudo uses this internally but the IPC gate blocks it by design.
#           Frontend callers that hit this path receive a Security throw,
#           which surfaces the error explicitly rather than silently degrading.
